# Document Transitive Dependencies and Dependency Tree

## Task Brief
Audit your project dependency tree, document all transitive dependencies, and explain resolution strategy.

## Scenario
Your team needs visibility into the full dependency tree. Audit transitive dependencies, document their purposes, and explain how conflicts are resolved.

## Deliverables
- Dependency tree diagram or table
- Transitive dependency audit
- Conflict resolution notes

## Success Criteria
- All direct and transitive deps listed
- Purpose of each transitive dep explained
- Resolution strategy documented
