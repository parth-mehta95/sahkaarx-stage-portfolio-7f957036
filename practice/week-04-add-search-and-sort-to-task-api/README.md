# Add Search and Sort to Task API

## Task Brief
Implement search and sort endpoints in your existing Django REST API using efficient collection operations.

## Scenario
Product team needs task search and filtering. Extend your existing Django API to support search by title and sort by date or priority.

## Deliverables
- Search endpoint in views.py
- Sort query parameter handling

## Success Criteria
- Search filters tasks by title or description
- Sort orders results by date or priority correctly
