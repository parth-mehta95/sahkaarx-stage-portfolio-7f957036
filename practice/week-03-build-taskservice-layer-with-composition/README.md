# Build TaskService Layer with Composition

## Task Brief
Implement a TaskService layer using composition to separate business logic from API views in your Django project.

## Scenario
Your backend team needs cleaner separation of concerns. Refactor your existing views to use a TaskService class that handles business logic.

## Deliverables
- TaskService class in services.py
- Updated views using TaskService

## Success Criteria
- Service encapsulates all task operations
- Views delegate to service cleanly
