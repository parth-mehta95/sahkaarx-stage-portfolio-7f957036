# Migrate Django Project to pyproject.toml and Lock Workflow

## Task Brief
Refactor your capstone project to use pyproject.toml, generate lock file, and document all transitive dependencies.

## Scenario
Your team requires reproducible builds and modern Python packaging. Migrate the Task Manager to pyproject.toml and establish a lock file workflow.

## Deliverables
- pyproject.toml with all dependencies
- requirements.lock file
- Dependency audit document

## Success Criteria
- Project installs from lock file reproducibly
- All transitive deps documented
- Lock file tracks exact versions
