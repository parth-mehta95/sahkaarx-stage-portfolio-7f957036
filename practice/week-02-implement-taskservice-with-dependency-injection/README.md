# Implement TaskService with Dependency Injection

## Task Brief
Build TaskService layer with injected dependencies; refactor existing views to use the service.

## Scenario
Your team needs a decoupled service layer. Implement TaskService with constructor injection and refactor Task API views to use it.

## Deliverables
- TaskService class with injected dependencies
- Refactored views using TaskService
- Unit tests for TaskService

## Success Criteria
- Service accepts dependencies via constructor
- All CRUD operations work through service
- Views delegate to service layer
