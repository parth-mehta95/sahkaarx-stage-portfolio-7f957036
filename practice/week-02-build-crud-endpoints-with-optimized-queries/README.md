# Build CRUD Endpoints with Optimized Queries

## Task Brief
Create Django REST views for task list, create, retrieve, update, delete using efficient collection operations.

## Scenario
Product team needs working CRUD endpoints. Implement views and URL routing in your existing Django project to expose task operations.

## Deliverables
- ViewSet or APIView classes
- URL routing configuration

## Success Criteria
- All CRUD endpoints respond correctly
- Serializer used for request/response
